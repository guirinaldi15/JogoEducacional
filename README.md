# Alfabetização Infantil Interativa

Aplicativo web funcional em React + TypeScript + Vite.

## Recursos
- Tela inicial, perfil infantil e navegação responsiva
- Letras com áudio, sílabas, formação de palavras, leitura e escrita em canvas
- Jogo de identificação de letras
- Pontos, estrelas, conquistas e progresso persistido em LocalStorage
- Área dos responsáveis com indicadores e histórico
- Feedback positivo e interface infantil responsiva

## Rodar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

> Os dados são demonstrativos e o acompanhamento pedagógico não substitui avaliação profissional do professor.
